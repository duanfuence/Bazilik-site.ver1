# Сайт ресторана «Базилик», Тамбов

Сайт ресторана «Базилик» (Тамбов, ул. Селезнёвская, 2А, тел. 55-82-53): меню, онлайн-заявки на бронирование и банкеты, страницы шефа, ресторана и контакты.

Стек: **Astro 7**. Все страницы — статический HTML, серверная часть — только API заявок на Node. Дальше: **TypeScript**, обычный CSS с дизайн-токенами, самостоятельно размещённые шрифты (Bona Nova + Onest). Клиентского фреймворка нет: на странице ~32 КБ JS (до сжатия), и только там, где он нужен.

## Быстрый старт

```bash
npm install
npm run dev            # разработка: http://localhost:4321

npm run build          # сборка в dist/
cp .env.example .env   # заполните SITE_URL и хотя бы один канал доставки заявок
npm run preview        # продакшен-сервер: node dist/server/entry.mjs
```

Нужен Node.js ≥ 22.12. Переменные окружения читаются из среды процесса. При запуске через systemd/Docker передайте их там, `.env` подхватывается только в `astro dev`.

## Где менять содержимое

Данные отделены от вёрстки. Обычные правки не требуют трогать компоненты.

| Что | Файл |
|---|---|
| Адрес, телефон, часы работы, соцсети, карта, правила онлайн-заявок | `src/config/site.ts` |
| Меню: разделы, блюда, цены, выход, фото | `src/data/menu.ts` |
| Фотографии сайта и бриф для съёмки | `src/data/photos.ts` |
| Шеф: награды, опыт, цитата | `src/data/chef.ts` |
| Банкеты: поводы, шаги, факты (вместимость, депозит) | `src/data/events.ts` |
| Тексты страницы «О ресторане» | `src/data/about.ts` |
| Схема зала (заготовка) | `src/data/floor-plan.ts` |
| Цвета, шрифты, размеры, отступы | `src/styles/tokens.css` |

**Как добавить фотографию.** Положите файл в `src/assets/photos/`, импортируйте его в `src/data/photos.ts` и укажите `src` у нужного слота. Astro сам сделает AVIF/WebP нескольких размеров, `srcset`, ленивую загрузку и сохранит пропорции. Для блюд то же самое делается полем `photo` в `menu.ts`.

## Заявки: как они доставляются

Заявка — это **не подтверждённая бронь**. Гость видит номер заявки (например, `Б-7KQ2M`) и сообщение о том, что администратор перезвонит для подтверждения.

Каналы доставки включаются переменными окружения (см. `.env.example`). Можно включить несколько сразу:

- `TELEGRAM_BOT_TOKEN` + `TELEGRAM_CHAT_ID` — сообщение в чат администраторов;
- `REQUESTS_WEBHOOK_URL` (+ `REQUESTS_WEBHOOK_SECRET`) — JSON в CRM, Make, n8n или собственный сервис;
- `REQUESTS_LOG_FILE` — журнал JSON Lines (для разработки или как резервная копия).

**Если не настроен ни один канал**, API отвечает `503 not_configured`, а сайт честно сообщает гостю, что онлайн-приём недоступен, и показывает телефон. Фиктивного «успеха» нет.

Защита: проверка данных на клиенте и повторно на сервере (общий код `src/lib/validation.ts`), скрытое поле-ловушка для ботов, ограничение 5 заявок за 10 минут с одного адреса, встроенная проверка Origin от Astro против межсайтовой отправки форм. Секреты читаются только на сервере.

> Ограничение частоты хранится в памяти процесса и определяет адрес гостя по `X-Forwarded-For`. Ставьте сервер за обратный прокси (nginx, Caddy), который перезаписывает этот заголовок. Если процессов несколько, лимит нужно перенести в Redis.

## Развёртывание

1. `SITE_URL=https://ваш-домен npm run build` — адрес нужен для canonical, Open Graph, sitemap и проверки Origin.
2. Запустите `node dist/server/entry.mjs` с переменными `HOST`, `PORT` и каналами доставки.
3. Поставьте перед ним nginx/Caddy: HTTPS, сжатие gzip/brotli, долгий кэш для `/_astro/*` (имена файлов содержат хеш).

## Дизайн-концепция «Тетрадь шефа»

- **Характер.** Тёплый городской ресторан с точностью кондитера: шеф — победитель номинации «Лучший кондитер России». Сайт выглядит как рабочая тетрадь шефа и печатное меню, а не как «премиальный» чёрный шаблон.
- **Цвет.** Тёплая бумага, чернила и томатно-красный акцент: базилик и томат — естественная пара, поэтому сайт не «зелёный по названию». Тёмный «базиликово-оливковый» используется точечно — для шефа и подвала. Все текстовые пары проходят WCAG AA.
- **Типографика.** Bona Nova (кириллица, каллиграфичный курсив для акцентов) в заголовках, Onest в тексте. Размеры адаптивные через `clamp()`.
- **Композиция.** Редакционная сетка на 12 колонок с асимметрией и наложениями. Нумерованные разделы с тонкими линейками, подписи к кадрам как в журнале. Секции чередуются: бумага → полоса → лента → тёмный шеф → галерея → томатные банкеты → адрес.
- **Меню.** Фотогеничные разделы — горизонтальные ленты-коллажи с разной высотой, шириной и смещением кадров. Остальные — типографские списки с отточием до цены. Навигация по разделам липкая, листается пальцем на телефоне.
- **Фото.** Пока снимков нет, заглушки оформлены как раскадровка: пропорции кадра и бриф («Зал вечером: свет ламп…»). Это одновременно готовый список съёмки для фотографа.
- **Движение.** Мягкое появление блоков, подчёркивания, раскрытие меню. При `prefers-reduced-motion` движение отключается. Бесконечных анимаций и параллакса нет.
- **Телефон.** Нижняя панель «Позвонить / Меню / Забронировать» под большим пальцем, на странице брони — сначала форма.
